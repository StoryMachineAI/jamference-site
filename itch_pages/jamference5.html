<p style="margin:0 0 10px;color:#ffc93c;font-size:13px;font-weight:700">ONE WEEK &nbsp;·&nbsp; ONE THEME &nbsp;·&nbsp; ONE RESTRICTION</p>

<h1 style="margin:0 0 16px;color:#ffffff;font-size:32px;font-weight:700">Welcome to Jamference</h1>

<p style="margin:0 0 14px;color:#eef1f6;font-size:17px">Jamference is a game jam built around one idea: making games <em>with</em> AI, out in the open. You get a theme up front, a surprise restriction at the starting bell, and one week to ship something playable. The week after that, everyone plays and rates what everyone else made.</p>

<p style="margin:0 0 16px"><span style="background:#0e1526;border:2px dashed #ffc93c;color:#ffc93c;font-size:15px;font-weight:700;padding:6px 14px">JAM + INFERENCE = JAMFERENCE</span></p>

<p style="margin:0 0 14px;color:#eef1f6;font-size:17px">Everyone starts from the same two prompts and ends up somewhere completely different. That's the fun part. Build solo, build with friends, build with a model in the loop. As long as something playable exists at the deadline, you're in.</p>

<p style="margin:0 0 14px;color:#eef1f6;font-size:17px">The full week is there to make it easier to take part, not a bar you have to clear. Your game can be one prompt or a full week of work, a tiny toy or something huge. Just make something fun. New to jams? This is a good one to start with.</p>

<p style="margin:0;color:#eef1f6;font-size:17px"><a style="color:#ffc93c;font-weight:700" href="https://discord.gg/Z99aJaBMQj" target="_blank" rel="nofollow noopener">Join the Discord server</a> if you have questions, want to hear the restriction the moment it drops, or just want to hang out with the other jammers.</p>

</div>

<div style="background:#18213a;color:#eef1f6;border-top:6px solid #ff9a3c;padding:24px 26px 26px;margin:0 0 20px" class="custom-section custom-section-theme">

<h1 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">Theme and restriction</h1>

<table style="width:100%;border-collapse:collapse;margin:0 0 20px" class="jam-pills">

<tbody><tr>

<td style="width:50%;padding:0 8px 0 0">

<div style="background:#0e1526;border:3px solid #ffc93c;padding:14px 12px 16px;text-align:center">

<p style="margin:0 0 6px;color:#aab7cf;font-size:12px;font-weight:700" class="label">THEME</p>

<p style="margin:0;color:#ffc93c;font-size:23px;font-weight:700">The Game is Out to Get You</p>

</div>

</td>

<td style="width:50%;padding:0 0 0 8px">

<div style="background:#0e1526;border:3px dashed #c9b3ff;padding:14px 12px 16px;text-align:center">

<p style="margin:0 0 6px;color:#aab7cf;font-size:12px;font-weight:700" class="label">RESTRICTION</p>

<p style="margin:0;color:#c9b3ff;font-size:23px;font-weight:700">To Be Announced</p>

</div>

</td>

</tr>

</tbody></table>

<p style="margin:0 0 14px;color:#eef1f6;font-size:17px">This time the game is not on your side. The floor gives way the moment you trust it. The checkpoint was a trap. The friendly NPC is lying, the menu button moves when you reach for it, and the boss has been reading your inputs since the title screen. The game wants you to lose, and it is not being subtle about it.</p>

<p style="margin:0 0 14px;color:#eef1f6;font-size:17px">The dream: games that feel deeply, hilariously unfair, and that you still can't put down. A platformer where the level rearranges itself behind you. A dungeon whose AI game master rewrites the rules every time you get comfortable. A boss that learns your favourite move and starts countering it. A puzzle game where the hint system is quietly trying to sabotage you. A shop that raises its prices every time you die. The player should be shouting "that's not fair!" and hitting restart in the same breath.</p>

<p style="margin:0 0 18px;color:#eef1f6;font-size:17px">But any take on a game that is out to get you is fair game: a rigged casino, a haunted cartridge, a level designer who hates you personally, a tutorial that gets less helpful the better you play, or a game that cheats and dares you to catch it. The theme is a launchpad, not a leash. Nobody is checking your homework against a definition.</p>

<div style="background:#0e1526;border-left:6px solid #ffc93c;padding:16px 20px 18px;margin:0 0 18px">

<p style="margin:0 0 10px;color:#ffc93c;font-size:13px;font-weight:700">UNFAIR, NOT UNWINNABLE</p>

<p style="margin:0 0 10px;color:#eef1f6;font-size:15px">The trick to this theme is that the game should <em>feel</em> unfair while still being <strong style="font-weight:700">beatable with skill</strong>. Frustration is the seasoning, not the meal. A coin flip that kills you is not a game; a trap you fall for once, understand, and then outplay is.</p>

<p style="margin:0 0 6px;color:#eef1f6;font-size:15px">A few things that keep the cruelty fun:</p>

<p style="margin:0 0 4px;color:#eef1f6;font-size:15px"><strong style="font-weight:700;color:#ff5a5a">Fail fast.</strong> Instant restarts, short runs, checkpoints that are (mostly) honest. Dying should cost seconds, not minutes.</p>

<p style="margin:0 0 4px;color:#eef1f6;font-size:15px"><strong style="font-weight:700;color:#ff9a3c">Make it learnable.</strong> The game can trick you, but the trick should work the same way twice so players can read it and beat it.</p>

<p style="margin:0 0 4px;color:#eef1f6;font-size:15px"><strong style="font-weight:700;color:#4fd8ff">Leave a way out.</strong> Every dirty mechanic should have a counter: a tell, a timing window, an exploit the game didn't think you'd find.</p>

<p style="margin:0;color:#eef1f6;font-size:15px"><strong style="font-weight:700;color:#ffc93c">Let them win.</strong> The best feeling in this jam should be beating the thing that was cheating. Make sure that moment exists.</p>

</div>

<div style="background:#0e1526;border:3px dashed #c9b3ff;padding:18px 20px 20px">

<p style="margin:0 0 10px;color:#c9b3ff;font-size:13px;font-weight:700">RESTRICTION: TO BE ANNOUNCED AT THE BELL</p>

<p style="margin:0 0 10px;color:#aab7cf;font-size:16px;font-weight:700;letter-spacing:2px">▓▓▓▓▓ ▓▓▓▓▓▓▓▓ ▓▓ ▓▓▓▓▓ ▓▓▓▓▓▓▓ ▓▓▓▓</p>

<p style="margin:0 0 10px;color:#eef1f6;font-size:15px">The restriction lands the second the jam opens, not a minute before. Nobody gets a head start, and nobody gets to pre-build around it. <a style="color:#ffc93c;font-weight:700" href="https://discord.gg/Z99aJaBMQj" target="_blank" rel="nofollow noopener">Join the Discord</a> to hear it the moment it drops.</p>

<p style="margin:0;color:#eef1f6;font-size:15px">And unlike the theme, the restriction is <strong style="font-weight:700">mandatory</strong>.</p>

</div>

<h1 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">Rules</h1>

<div class="custom-rules">

<div style="background:#0e1526;border-left:6px solid #ff9a3c;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#ff9a3c;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">1</span> &nbsp;AI must be part of the build &nbsp;<span style="background:#ff9a3c;color:#0a1020;font-size:12px;font-weight:700;padding:3px 8px">REQUIRED</span></p>

<p style="margin:0;color:#aab7cf;font-size:15px">This is the rule that defines the jam. AI has to be genuinely involved somewhere: code, art, audio, writing, level generation, design ideation, or as a live system inside the game itself. "I used it for a variable name" does not count; we are looking for AI doing real work. Tell us what you used and where.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #c9b3ff;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#c9b3ff;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">2</span> &nbsp;The restriction is mandatory &nbsp;<span style="background:#c9b3ff;color:#0a1020;font-size:12px;font-weight:700;padding:3px 8px">REQUIRED</span></p>

<p style="margin:0;color:#aab7cf;font-size:15px">The theme is optional inspiration. The restriction is not. Incorporate it, and be ready to explain how in a sentence.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #ff5a5a;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#ff5a5a;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">3</span> &nbsp;Build it during the jam week</p>

<p style="margin:0;color:#aab7cf;font-size:15px">Games must be made inside the one week build window. Existing projects, prototypes you have been sitting on, and last month's abandoned build are not eligible.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #4fd8ff;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#4fd8ff;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">4</span> &nbsp;Reused assets are fine if they are yours to reuse</p>

<p style="margin:0;color:#aab7cf;font-size:15px">Your own libraries, your own engine, your own tooling, licensed asset packs, AI generated assets are all allowed. Just make sure you have the right to use them, and credit anything that needs crediting.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #ff7ab6;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#ff7ab6;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">5</span> &nbsp;Keep it broadly safe for everyone</p>

<p style="margin:0;color:#aab7cf;font-size:15px">No NSFW content, targeted harassment, or hate. If your game contains anything intense, such as horror, gore, flashing imagery or heavy themes, flag it clearly on your submission page.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #ffc93c;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#ffc93c;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">6</span> &nbsp;Be nice</p>

<p style="margin:0;color:#aab7cf;font-size:15px">This is a place to make games and have fun.&nbsp; Give constructive feedback and don't bash anyone for how they use AI.</p>

</div>

<div style="background:#0e1526;border-left:6px solid #aab7cf;padding:14px 18px 16px;margin:0 0 18px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#aab7cf;color:#0a1020;font-size:15px;font-weight:700;padding:2px 9px">7</span> &nbsp;Disclose your team</p>

<p style="margin:0;color:#aab7cf;font-size:15px">Solo, duo, or squad, all fine. Just list who did what, and say so if you are contributing to more than one entry.</p>

</div>

</div>

<p style="margin:0;color:#aab7cf;font-size:16px">Any game that does not follow the rules <em>may be removed</em> from the jam without warning.</p>

</div>

<div style="background:#18213a;color:#eef1f6;border-top:6px solid #c9b3ff;padding:24px 26px 26px;margin:0 0 20px" class="custom-section custom-section-faq">

<h2 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">FAQ</h2>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Do I have to follow the theme?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">"The Game is Out to Get You" is there to spark ideas. Only the restriction is compulsory. Skipping it will not disqualify you, but Theme is one of the four rating categories, so a game that ignores it will score lower there.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Does "out to get you" mean it has to be really hard?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Not necessarily. It has to feel like the game is working against the player, but that can be cheeky rather than brutal. A game that lies, cheats, mocks or misdirects you is on theme even if it is short and easy. What matters is that a skilled or clever player can still get the better of it, and that losing is part of the fun.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can the AI be the thing that is out to get me?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Please. A live model that adapts to the player, taunts them, rewrites the level, or bends the rules mid-run is a perfect fit, and it counts toward the AI use category too. Just keep it beatable: a model with no limits on how hard it can cheat stops being fun very quickly.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Which AI tools can I use?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Any of them. Coding assistants, image and audio models, agents, local models, whatever you have got. Combine them freely.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Do I need to disclose which tools I used?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Yes, briefly, on your submission. No essay required; a short list of tools and what each one did is plenty.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I build a game <em>about</em> AI instead of using AI?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">You can do both, and plenty of people will. But rule 1 still stands: AI has to be part of how the thing got made or how it runs.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">What engine can I use?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Whatever you are fastest in. Unity, Godot, Unreal, Bevy, plain HTML and JavaScript, Twine, a spreadsheet with delusions of grandeur. No restrictions.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">What kind of game can I make?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Any genre, any platform. Web builds get played the most, so if you want ratings, a browser version helps enormously.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Does my game have to be playable in the browser?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">It is recommended but not required. A web build gets played and rated far more than a download, because most people rating are clicking through a long list of entries. If you can only ship a downloadable build, that is still a valid entry.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I submit more than one entry?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Yes. Each one is judged on its own merits, and each needs its own submission page.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I keep working on it during rating week?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Bug fixes are fine, and encouraged if something is broken enough to block play. Adding features, content or art is not, because everyone should be rated on the same build. Keep the deadline version playable all week and label any post jam version clearly.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">How is the winner decided?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Fun, AI use, Polish and Theme are averaged into a single score. Highest average takes it.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">I missed the deadline. Now what?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Get in touch in the Discord or the jam community tab as soon as you can. Late submissions are handled case by case; the earlier you say something, the more we can do.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Is there a prize?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">Bragging rights, a leaderboard, and a pile of games that did not exist a fortnight ago. The real prize is finding out what you can ship in a week with AI riding shotgun.</p>

</details>

<details style="background:#0e1526;border-left:5px solid #4fd8ff;padding:12px 16px;margin:0">

<summary style="color:#ffffff;font-size:16px;font-weight:700">When is the next one?</summary>

<p style="margin:10px 0 0;color:#aab7cf;font-size:15px">We will be hosting jams every two weeks.&nbsp; Keep an eye out for the next one!</p>

</details>
