<p style="margin:0 0 10px;color:#52d2e6;font-size:13px;font-weight:700">ONE WEEK &nbsp;·&nbsp; ONE THEME &nbsp;·&nbsp; ONE RESTRICTION</p>

<h1 style="margin:0 0 16px;color:#ffffff;font-size:32px;font-weight:700">Welcome to Jamference</h1>

<p style="margin:0 0 14px;color:#eaf6fb;font-size:17px">Jamference is a game jam built around one idea: making games <em>with</em> AI, out in the open. You get a theme up front, a surprise restriction at the starting bell, and one week to ship something playable. The week after that, everyone plays and rates what everyone else made.</p>

<p style="margin:0 0 16px"><span style="background:#16334a;border:2px dashed #f0954a;color:#f0954a;font-size:15px;font-weight:700;padding:6px 14px">JAM + INFERENCE = JAMFERENCE</span></p>

<p style="margin:0 0 14px;color:#eaf6fb;font-size:17px">Everyone starts from the same two prompts and ends up somewhere completely different. That's the fun part. Build solo, build with friends, build with a model in the loop. As long as something playable exists at the deadline, you're in.</p>

<p style="margin:0 0 14px;color:#eaf6fb;font-size:17px">The full week is there to make it easier to take part, not a bar you have to clear. Your game can be one prompt or a full week of work, a tiny toy or something huge. Just make something fun. New to jams? This is a good one to start with.</p>

<p style="margin:0;color:#eaf6fb;font-size:17px"><a style="color:#f0954a;font-weight:700" href="https://discord.gg/Z99aJaBMQj" target="_blank" rel="nofollow noopener">Join the Discord server</a> if you have questions, want to hear the restriction the moment it drops, or just want to hang out with the other jammers.</p>

</div>

<h1 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">Theme and restriction</h1>

<table style="width:100%;border-collapse:collapse;margin:0 0 20px" class="jam-pills">

<tbody><tr>

<td style="width:50%;padding:0 8px 0 0">

<div style="background:#16334a;border:3px solid #f0954a;padding:14px 12px 16px;text-align:center">

<p style="margin:0 0 6px;color:#a9c3d4;font-size:12px;font-weight:700" class="label">THEME</p>

<p style="margin:0;color:#f0954a;font-size:23px;font-weight:700">Cat and Robot</p>

</div>

</td>

<td style="width:50%;padding:0 0 0 8px">

<div style="background:#16334a;border:3px solid #a283de;padding:14px 12px 16px;text-align:center">

<p style="margin:0 0 6px;color:#a9c3d4;font-size:12px;font-weight:700" class="label">RESTRICTION</p>

<p style="margin:0;color:#a283de;font-size:23px;font-weight:700">Movement Input Only</p>

</div>

</td>

</tr>

</tbody></table>

<p style="margin:0 0 18px;color:#eaf6fb;font-size:17px">The theme is a launchpad, not a leash. Take it literally, take it sideways, or take it apart: a stray cat and a scrapyard drone, a robot convinced it <em>is</em> a cat, two rival AIs named Cat and Robot. Nobody is checking your homework against a definition.</p>

<div style="background:#16334a;border:3px dashed #f0954a;padding:18px 20px 20px">

<p style="margin:0 0 10px;color:#f0954a;font-size:13px;font-weight:700">RESTRICTION: MOVEMENT INPUT ONLY</p>

<p style="margin:0;color:#eaf6fb;font-size:15px">

</p><p>All inputs can map only to player movement.  No attack button, no shoot button, no clickable button selection ui, only movement.</p>

<p>Example games that match this restriction: Flappy Bird, Snake, Super Mario (without the fireballs), Super Meat Boy.  I even include Tetris since you are only moving the pieces.  Vampire Survivors is close, but the upgrade selection menu would be an input without movement. </p>

<p>And unlike the theme, the restriction is <strong style="font-weight:700">mandatory</strong>.</p>

</div>

</div>

<p style="margin:0 0 18px;color:#eaf6fb;font-size:17px">Three categories, weighted equally. The three scores are averaged, and the highest average wins.</p>

<p style="margin:0;padding:12px 14px 14px;color:#a9c3d4;font-size:15px">Was the game actually good to play? This is the one that matters most, because it is the whole point of making games.</p>

<p style="margin:0;background:#52d2e6;color:#102433;font-size:20px;font-weight:700;padding:10px 14px 11px">AI use</p>

<div style="background:#1b3a52;color:#eaf6fb;border-top:6px solid #ffce5e;padding:24px 26px 26px;margin:0 0 20px" class="custom-section custom-section-rules">

<h1 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">Rules</h1>

<div class="custom-rules">

<div style="background:#16334a;border-left:6px solid #f0954a;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#f0954a;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">1</span> &nbsp;AI must be part of the build &nbsp;<span style="background:#f0954a;color:#102433;font-size:12px;font-weight:700;padding:3px 8px">REQUIRED</span></p>

<p style="margin:0;color:#a9c3d4;font-size:15px">This is the rule that defines the jam. AI has to be genuinely involved somewhere: code, art, audio, writing, level generation, design ideation, or as a live system inside the game itself. "I used it for a variable name" does not count; we are looking for AI doing real work. Tell us what you used and where.</p>

</div>

<div style="background:#16334a;border-left:6px solid #a283de;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#a283de;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">2</span> &nbsp;The restriction is mandatory &nbsp;<span style="background:#a283de;color:#102433;font-size:12px;font-weight:700;padding:3px 8px">REQUIRED</span></p>

<p style="margin:0;color:#a9c3d4;font-size:15px">The theme is optional inspiration. The restriction is not. Incorporate it, and be ready to explain how in a sentence.</p>

</div>

<div style="background:#16334a;border-left:6px solid #85d372;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#85d372;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">3</span> &nbsp;Build it during the jam week</p>

<p style="margin:0;color:#a9c3d4;font-size:15px">Games must be made inside the one week build window. Existing projects, prototypes you have been sitting on, and last month's abandoned build are not eligible.</p>

</div>

<div style="background:#16334a;border-left:6px solid #52d2e6;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#52d2e6;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">4</span> &nbsp;Reused assets are fine if they are yours to reuse</p>

<p style="margin:0;color:#a9c3d4;font-size:15px">Your own libraries, your own engine, your own tooling, licensed asset packs, AI generated assets are all allowed. Just make sure you have the right to use them, and credit anything that needs crediting.</p>

</div>

<div style="background:#16334a;border-left:6px solid #f06bb2;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#f06bb2;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">5</span> &nbsp;Keep it broadly safe for everyone</p>

<p style="margin:0;color:#a9c3d4;font-size:15px">No NSFW content, targeted harassment, or hate. If your game contains anything intense, such as horror, gore, flashing imagery or heavy themes, flag it clearly on your submission page.</p>

</div>

<div style="background:#16334a;border-left:6px solid #ffce5e;padding:14px 18px 16px;margin:0 0 12px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#ffce5e;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">6</span> &nbsp;Be nice</p>

<p style="margin:0;color:#a9c3d4;font-size:15px">This is a place to make games and have fun.&nbsp; Give constructive feedback and don't bash anyone for how they use AI.</p>

</div>

<div style="background:#16334a;border-left:6px solid #a9c3d4;padding:14px 18px 16px;margin:0 0 18px">

<p style="margin:0 0 6px;color:#ffffff;font-size:19px;font-weight:700"><span style="background:#a9c3d4;color:#102433;font-size:15px;font-weight:700;padding:2px 9px">7</span> &nbsp;Disclose your team</p>

<p style="margin:0;color:#a9c3d4;font-size:15px">Solo, duo, or squad, all fine. Just list who did what, and say so if you are contributing to more than one entry.</p>

</div>

</div>

<p style="margin:0;color:#a9c3d4;font-size:16px">Any game that does not follow the rules <em>may be removed</em> from the jam without warning.</p>

</div>

<div style="background:#1b3a52;color:#eaf6fb;border-top:6px solid #a283de;padding:24px 26px 26px;margin:0 0 20px" class="custom-section custom-section-faq">

<h2 style="margin:0 0 18px;color:#ffffff;font-size:28px;font-weight:700">FAQ</h2>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Do I have to follow the theme?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">"Cat and Robot" is there to spark ideas. Only the restriction is compulsory.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Which AI tools can I use?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Any of them. Coding assistants, image and audio models, agents, local models, whatever you have got. Combine them freely.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Do I need to disclose which tools I used?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Yes, briefly, on your submission. No essay required; a short list of tools and what each one did is plenty.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I build a game <em>about</em> AI instead of using AI?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">You can do both, and plenty of people will. But rule 1 still stands: AI has to be part of how the thing got made or how it runs.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">What engine can I use?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Whatever you are fastest in. Unity, Godot, Unreal, Bevy, plain HTML and JavaScript, Twine, a spreadsheet with delusions of grandeur. No restrictions.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">What kind of game can I make?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Any genre, any platform. Web builds get played the most, so if you want ratings, a browser version helps enormously.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Does my game have to be playable in the browser?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">It is recommended but not required. A web build gets played and rated far more than a download, because most people rating are clicking through a long list of entries. If you can only ship a downloadable build, that is still a valid entry.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I submit more than one entry?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Yes. Each one is judged on its own merits, and each needs its own submission page.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Can I keep working on it during rating week?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Bug fixes are fine, and encouraged if something is broken enough to block play. Adding features, content or art is not, because everyone should be rated on the same build. Keep the deadline version playable all week and label any post jam version clearly.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">How is the winner decided?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Fun, AI use, and Polish are averaged into a single score. Highest average takes it.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">I missed the deadline. Now what?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Get in touch in the Discord or the jam community tab as soon as you can. Late submissions are handled case by case; the earlier you say something, the more we can do.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0 0 10px">

<summary style="color:#ffffff;font-size:16px;font-weight:700">Is there a prize?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">Bragging rights, a leaderboard, and a pile of games that did not exist a fortnight ago. The real prize is finding out what you can ship in a week with AI riding shotgun.</p>

</details>

<details style="background:#16334a;border-left:5px solid #52d2e6;padding:12px 16px;margin:0">

<summary style="color:#ffffff;font-size:16px;font-weight:700">When is the next one?</summary>

<p style="margin:10px 0 0;color:#a9c3d4;font-size:15px">We will be hosting jams every two weeks.&nbsp; Keep an eye out for the next one!</p>

</details>
